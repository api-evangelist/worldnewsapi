# World News API

> Real-time and historical news data from thousands of sources across 210+ countries and 86+ languages. Nine read-only REST operations cover full-text and semantic news search, geo-targeted local news search, country-level top-news clustering, newspaper front pages, article and link extraction from arbitrary URLs, news-source discovery, and website-to-RSS conversion. Authentication is a single API key. Usage is metered in points against a daily plan allowance.

Generated by API Evangelist on 2026-08-13 from the provider's published OpenAPI 3 document and documentation. The provider does not serve an llms.txt of its own (https://worldnewsapi.com/llms.txt returns the site homepage with HTTP 200, a soft 404).

- Base URL: https://api.worldnewsapi.com
- Auth: `api-key` query parameter or `x-api-key` request header. The provider recommends the header in production.
- Metering: 1 point per request plus 0.01 points per result returned, with per-endpoint exceptions. `X-API-Quota-Request`, `X-API-Quota-Used` and `X-API-Quota-Left` are returned on every successful response. Quota resets at midnight UTC.
- Errors: status code only, no body. 401 bad key, 402 quota exhausted, 403 plan does not include the feature, 404 not found, 406 not acceptable, 429 rate or concurrency exceeded. No Retry-After.
- Pagination: `offset` + `number` on search only; response returns `offset`, `number`, `available`.

## Operations

- [searchNews](https://worldnewsapi.com/docs/search-news/): GET /search-news — full-text, semantic and geo/local news search. Filter by text, source-country, language, sentiment range, publish-date range, news-sources, authors, categories, entities and location-filter.
- [topNews](https://worldnewsapi.com/docs/top-news/): GET /top-news — top news for a country and language on a date, clustered by coverage. Requires source-country and language.
- [retrieveNewsArticlesByIds](https://worldnewsapi.com/docs/retrieve-news/): GET /retrieve-news — retrieve full article records by comma-separated ids.
- [extractNews](https://worldnewsapi.com/docs/extract-news/): GET /extract-news — extract a structured article (title, text, images, videos, authors) from any news URL.
- [extractNewsLinks](https://worldnewsapi.com/docs/extract-news-links/): GET /extract-news-links — extract news links from a news website.
- [searchNewsSources](https://worldnewsapi.com/docs/search-news-sources/): GET /search-news-sources — check whether a publication is monitored.
- [retrieveNewspaperFrontPage](https://worldnewsapi.com/docs/newspaper-front-pages/): GET /retrieve-front-page — front pages for 6,000+ publications in 125+ countries, from 2024-07-09 onward. Paid plans.
- [getGeoCoordinates](https://worldnewsapi.com/docs/get-geo-coordinates/): GET /geo-coordinates — resolve a place name to latitude/longitude for use in `location-filter`.
- [newsWebsiteToRSSFeed](https://worldnewsapi.com/docs/website-to-rss-feed/): GET /feed.rss — turn a news website into an RSS 2.0 feed. Returns XML, not JSON.

## Local news search

Local news is a two-call flow, not a single parameter. Call `getGeoCoordinates` with a place name, then pass the result to `searchNews` as `location-filter=latitude,longitude,radius_km` with a radius between 1 and 100 km.

## Agent access

- [MCP server](https://worldnewsapi.com/docs/setup-news-mcp/): first-party, **local stdio only** — `npm install -g world-news-api-mcp`, key supplied as the `WORLD_NEWS_API_KEY` environment variable. There is no hosted remote MCP endpoint. Eight tools: search_news, get_top_news, retrieve_newspaper_front_page, retrieve_news_articles, extract_news, extract_news_links, search_news_sources, get_geo_coordinates.
- No A2A agent card is served on any host.
- No `/.well-known/` document is served on any host.
